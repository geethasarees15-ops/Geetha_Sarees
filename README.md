# Geetha Sarees

Online saree storefront for **Geetha Sarees** — silk and cotton sarees, wholesale and retail.

GitHub: [geethasarees15-ops/Geetha_Sarees](https://github.com/geethasarees15-ops/Geetha_Sarees)

## Stack

Next.js, GraphQL, Supabase, Drizzle, Tailwind CSS.

## Setup

1. Copy `.env.example` to `.env.local` and add **this shop’s** keys only (not another store’s keys).
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

Set `NEXT_PUBLIC_SITE_URL` to your Vercel or custom domain.

Brand copy lives in `src/config/site.ts`. Add address, GSTIN, and phones in Admin → Settings when ready.
